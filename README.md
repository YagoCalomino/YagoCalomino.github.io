# yagocalomino.github.io

Personal portfolio — yagocalomino.github.io

**Live site:** https://yagocalomino.github.io

## Stack

- [Next.js](https://nextjs.org) 16 (App Router, static export)
- [React](https://react.dev) 19
- [TypeScript](https://www.typescriptlang.org) 5
- [Tailwind CSS](https://tailwindcss.com) 4
- [Motion](https://motion.dev) / Framer Motion for animations
- [shadcn/ui](https://ui.shadcn.com) tooling (`class-variance-authority`, `clsx`, `tailwind-merge`)
- [Lucide](https://lucide.dev) icons
- ESLint 9

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Other scripts:

```bash
npm run build   # static export to ./out
npm run lint
```

Deployed to GitHub Pages via GitHub Actions.
